# OFFGRID-TRANSLATE

Chrome 内蔵のオンデバイスAI（[Translator API](https://developer.chrome.com/docs/ai/translator-api)）を使った、ブラウザだけで完結する英日翻訳ツールです。サーバーへの通信は一切行わず、翻訳はすべて端末内で処理されます。

## 特徴

- **オフライン翻訳**: Chrome 内蔵の翻訳モデルを使用するため、通信環境がなくても翻訳可能（初回はモデルのダウンロードが必要）
- **自動翻訳**: 入力を止めると自動で翻訳が走り、修正すると即座に反映
- **英⇔日 切り替え**: ボタン一つで翻訳方向を入れ替え
- **対応ハイライト**: 入力・出力どちらかの文章を選択すると、対応する段落がもう一方でハイライトされる
- **長文対応**: 長いテキストは段落・文単位に分割し、逐次翻訳しながら結果を表示

## 動作要件

- **Chrome 138 以降**（デスクトップ版のみ）
- 他のブラウザ（Safari / Firefox / Edge 等）やモバイル版 Chrome では動作しません

## 使い方

`index.html` を Chrome で直接開くだけで利用できます。ビルドや依存パッケージのインストールは不要です。

```
# ローカルで開く
open index.html   # macOS
start index.html  # Windows
```

## 技術構成

単一の `index.html` に HTML / CSS / JavaScript がすべて含まれています。ビルドツールやフレームワークは使用していません。実装の詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。
