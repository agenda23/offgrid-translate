# OFFGRID-TRANSLATE

Chrome 内蔵のオンデバイスAI（[Translator API](https://developer.chrome.com/docs/ai/translator-api)）を使った、ブラウザだけで完結する英日翻訳ツールです。サーバーへの通信は一切行わず、翻訳はすべて端末内で処理されます。

## 特徴

- **オフライン翻訳**: Chrome 内蔵の翻訳モデルを使用するため、通信環境がなくても翻訳可能（初回はモデルのダウンロードが必要）
- **自動翻訳**: 入力を止めると自動で翻訳が走り、修正すると即座に反映
- **英⇔日 切り替え**: ボタン一つで翻訳方向を入れ替え
- **対応ハイライト**: 入力・出力どちらかの文章を選択すると、対応する段落がもう一方でハイライトされる
- **長文対応**: 長いテキストは段落・文単位に分割し、逐次翻訳しながら結果を表示

## 動作要件

- **Chrome 138 以降**（デスクトップ版のみ）
- 他のブラウザ（Safari / Firefox / Edge 等）やモバイル版 Chrome では動作しません

## Chrome 側のセットアップ

このツールは Chrome 内蔵のオンデバイスAI（[Translator API](https://developer.chrome.com/docs/ai/translator-api)）を使用します。Chrome 138 以降であれば基本的に追加設定なしで動作しますが、初めて使う場合や動作しない場合は以下を確認してください。

1. **Chrome のバージョンを確認・更新する**
   アドレスバーに `chrome://settings/help` と入力し、Chrome を最新版に更新します（138 以降が必要）。

2. **翻訳モデルの初回ダウンロード**
   対応言語ペアの翻訳を初めて実行すると、翻訳モデル（数百MB程度）が自動でダウンロードされます。本ツールの画面上部にダウンロード進捗バーが表示されるので、完了するまで待ってください。ダウンロードにはネットワーク接続とある程度の空きディスク容量が必要です。

3. **言語モデルの状態確認・手動インストール**
   アドレスバーに `chrome://on-device-translation-internals` と入力すると、インストール済みの言語パックの状態を確認したり、手動でインストールしたりできます。ダウンロードが進まない場合はここで状況を確認してください。

4. **それでも動作しない場合（フラグの有効化）**
   Chrome のバージョンや設定によっては、実験的機能フラグが無効になっていることがあります。アドレスバーに `chrome://flags` と入力し、"Experimental translation API" などを検索して有効化した上で Chrome を再起動してください。

5. **Chrome を再起動する**
   設定変更後は Chrome を完全に再起動（全ウィンドウを閉じて再度起動）すると反映されやすくなります。

## 使い方

`index.html` を Chrome で直接開くだけで利用できます。ビルドや依存パッケージのインストールは不要です。

```
# ローカルで開く
open index.html   # macOS
start index.html  # Windows
```

## 技術構成

単一の `index.html` に HTML / CSS / JavaScript がすべて含まれています。ビルドツールやフレームワークは使用していません。実装の詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。
